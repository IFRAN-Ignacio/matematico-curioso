# Matemático Curioso

Implementación de la Conjetura de Collatz

Dada una semilla S, genera la secuencia donde:

- Si el número es par → se divide por 2
- Si el número es impar → se multiplica por 3 y se le suma 1
- La secuencia termina cuando llega a 1

El programa muestra el largo de la secuencia y el número más grande encontrado.

## Cómo usar

Abrí `matematico.html` en cualquier navegador. No requiere instalación.

## Archivos

- `matematico.html` — estructura de la página
- `matematico.css` — estilos
- `matematico.js` — lógica (vector, Collatz, DOM)

## Ejemplo

Semilla: 22 → largo: 16, máximo: 52
